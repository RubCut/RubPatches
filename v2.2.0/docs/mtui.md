# Свои стили интерфейса (.mtui)

В MargyT три стиля интерфейса: Material 3, Liquid Glass и Fluent. Стиль решает,
из чего сделаны карточки, меню и панели, какие у них углы и отступы, как они
двигаются и как выглядят переключатели. Файл `.mtui` описывает ещё один такой
стиль. Это обычный текстовый JSON, кода в нём нет, поэтому ставить чужие стили
безопасно.

Цвета стиль не задаёт: за них отвечают акцент и тема в настройках.

## Как поставить

- Открыть файл `.mtui` из файлового менеджера или Telegram и выбрать «Стиль
  MargyT». Мод покажет название, автора и основу и спросит, ставить ли.
- Или в настройках: Оформление → Стиль и значок → «Установить стиль .mtui».

Установленный стиль появляется в карусели рядом с тремя встроенными. Удалить его
можно долгим нажатием на его карточку.

## Как сделать свой

1. Выбрать встроенный стиль, на который новый будет похож.
2. Нажать «Сохранить стиль в файл». В файл запишутся все числа этого стиля.
3. Поменять в файле `name` и числа, которые хочется, и поставить файл обратно.

Готовый пример лежит в [examples/aero.mtui](../examples/aero.mtui).

## Файл целиком

```json
{
  "mtui": 1,
  "name": "Aero",
  "author": "narezany",
  "description": "Стекло помягче.",
  "base": "glass",
  "controls": "fluent",
  "corners": { "card": 20, "inner": 6, "sheet": 24, "small": 14, "bar": -1 },
  "gap": 3,
  "material": { "blur": 2.2, "tint": 0.3, "refraction": 0.6, "dispersion": 0.02, "grain": 0.003, "windowBlur": 32 },
  "motion": { "duration": 240, "bounce": 0.8, "press": 0.98 },
  "page": { "neutral": false, "cardLift": 0.06 }
}
```

Обязательны `mtui`, `name` и `base`. Всё остальное можно не писать: чего нет в
файле, то берётся у основы.

## Поля

| Поле | Что это |
|---|---|
| `mtui` | Версия формата. Сейчас `1`. |
| `name` | Название в карусели, до 40 знаков. |
| `author` | Автор, до 60 знаков. |
| `description` | Пара слов о стиле, до 400 знаков. |
| `base` | Основа: `md3`, `glass` или `fluent`. Решает, из чего сделаны поверхности: сплошной цвет, стекло с преломлением или размытый акрил, и как стоят строки в группах. |
| `controls` | Переключатели, ползунки, значки строк и загрузка: `md3`, `glass` или `fluent`. По умолчанию как у основы. Так можно взять стекло и переключатели от Fluent. |
| `corners` | Скругления в dp, см. ниже. |
| `gap` | Отступ между строками в группе, dp, от 0 до 16. |
| `material` | Материал стекла и акрила, см. ниже. Для основы `md3` не действует. |
| `motion` | Анимации, см. ниже. |
| `page` | Фон страниц и карточек, см. ниже. |

### corners

Все числа в dp, от 0 до 40.

| Поле | Что скругляет |
|---|---|
| `card` | Карточки и группы строк. |
| `inner` | Строки внутри группы, там где они касаются друг друга. |
| `sheet` | Листы снизу, например лист комментариев. |
| `small` | Мелкие элементы: поле ввода, кнопки. |
| `bar` | Нижняя панель-капсула. `-1` даёт круглые края (таблетку). |

### material

| Поле | Что это | Пределы |
|---|---|---|
| `blur` | Насколько размыто то, что под поверхностью. | 0…4 |
| `tint` | Насколько цвет поверхности закрывает то, что под ней (акрил). | 0…1 |
| `refraction` | Сила преломления по краям (стекло). `0` без преломления, `1` как в Liquid Glass. | 0…2 |
| `dispersion` | Радуга по краю стекла. | 0…0.3 |
| `grain` | Зерно на акриле. | 0…0.05 |
| `windowBlur` | Размытие за всплывающими окнами, dp (Android 12 и новее). | 0…60 |

### motion

| Поле | Что это | Пределы |
|---|---|---|
| `duration` | Длительность анимаций переключения, мс. | 60…1000 |
| `bounce` | Пружинистость в конце анимации. `0` плавная остановка без отскока. | 0…4 |
| `press` | Во сколько раз меняется поверхность под пальцем: меньше 1 вдавливается, больше 1 приподнимается. | 0.9…1.1 |

### page

| Поле | Что это | Пределы |
|---|---|---|
| `neutral` | `true` красит страницы мода в нейтральные серые вместо цвета TikTok. | |
| `cardLift` | Насколько карточка светлее или темнее страницы. | 0…0.3 |

## Встроенные стили в числах

| | Material 3 | Liquid Glass | Fluent |
|---|---|---|---|
| `corners` card / inner / sheet / small / bar | 16 / 4 / 28 / 24 / -1 | 26 / 6 / 28 / 24 / -1 | 8 / 6 / 8 / 4 / 8 |
| `gap` | 2 | 0 | 4 |
| `material` blur / tint / refraction / dispersion / grain / windowBlur | | 1.45 / 0.24 / 1 / 0.065 / 0.003 / 26 | 1.15 / 0.24 / 0 / 0 / 0.003 / 4 |
| `motion` duration / bounce / press | 300 / 1.6 / 0.985 | 300 / 1.6 / 1.025 | 180 / 0 / 0.995 |
| `page` neutral / cardLift | false / 0.045 | false / 0.045 | true / 0.075 |

## Что происходит при установке

- Если в файле ошибка (число вне пределов, неизвестная основа, нет названия),
  стиль не ставится, и мод пишет, что не так.
- Незнакомые поля пропускаются: стиль для будущей версии с новыми полями всё
  равно встанет, если его `mtui` не больше, чем знает мод.
- Стиль с тем же названием заменяет прежний.
- Файл больше 32 КБ не принимается.
